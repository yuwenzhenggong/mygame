# 丛林獠兽 v1

普通与精英属于同一族群：灰黑毛皮、琥珀色眼睛、低伏四足、大前爪。
精英体型更大，带骨甲、短角和紫色异化裂纹。

## 交付与绑定

- 可编辑 SVG：`svg/normal.svg`、`svg/elite.svg`，以及所有逐帧 SVG。
- 普通：96×64；精英：132×88。所有帧保留固定画布、透明背景和命名分层。
- 普通、精英獠兽在 `WorldRoot.BuildEnemies` 中均额外乘以 0.7，整体比初稿缩小 30%。预览图同步按此比例显示，SVG 和 PNG 保留原分辨率。
- 每种 12 帧待机、24 帧行走、12 帧扑咬，共 96 张动画 PNG。
- 已安装到 `Assets/Resources/Art/enemy_beast*`、`enemy_elite*`，两个基础资源保留原 GUID。
- 普通行走每帧 0.035 秒；精英随较低移速放慢到 0.0525 秒，待机每帧 0.1 秒、攻击每帧 0.05 秒。
- `Enemy.cs` 根据待机、实际移动和攻击状态播放序列，朝右镜像。撞墙时停止行走帧，游戏面板暂停时冻结动画。
- 扑咬先蓄力，在约 0.25 秒的前扑张嘴时结算伤害；攻击期间停步，离开攻击距离可以躲开这一击。
- 丛林原四个刷新点改为三只普通獠兽、一只精英獠兽；刷新点 ID 保留。
- 主线任务目标和显示文字同步改为清剿普通异兽，保留原任务 ID、数量和奖励。

修改前的怪物基础图、元数据、配置与代码在 `backup-runtime/`；主角素材没有修改。
`build_art.py` 只生成原稿和导出素材，不自动覆盖游戏。依赖 NumPy、Pillow、resvg-py。
