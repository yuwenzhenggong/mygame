# 都市异能 Demo

一个 Unity 2021.3.19f1c1 制作的 2D 像素风「都市异能 ARPG + 据点经营」原型。

当前版本已经跑通完整的主线闭环：

**安全屋 → 街道 → 丛林 → 打怪 → 捡残响/素材 → 回据点炼化 → 接委托 → 凑齐条件 → 突破 → 自动存档**

详见下方「完整闭环」。

---

## 运行

1. 打开 Unity Hub。
2. 用 **Unity 2021.3.19f1c1** 打开本目录 `E:\mygame`。
3. 打开 `Assets/Scenes/Main.unity`，点击 Play。

场景和 HUD 由 `Bootstrap.cs` 自动创建，不需要手动往场景里拖对象。

---

## 操作

| 按键 | 功能 |
|---|---|
| `WASD` / 方向键 | 八方向移动 |
| `E` | 与附近的门、路灯、售货机等互动 |
| `J` | 普通攻击（连按可接第二段） |
| `B` | 打开 / 关闭背包 |
| `Esc` | 打开或关闭状态 HUD |

HUD 中提供存档、读档和重开按钮。进入互动面板时，移动和战斗会暂停。

## 当前完成内容

### 场景

目前有三个可切换场景：

- `safehouse`：安全屋，也是默认出生点和死亡复活点。
- `overworld`：都市街道，包含多个调查互动点。
- `jungle`：丛林战斗区，包含固定敌人刷新点。

场景配置位于 `Assets/Resources/Data/scenes.json`，每个场景由一张背景图、一份字符碰撞遮罩和出生点组成。传送点、死亡复活和存档都会记录当前场景。

### 战斗

- 玩家普通攻击：`J`，前方圆形范围判定，冷却 0.5 秒。
- 两段连招：左手直拳 → 右手直拳，第二段 1.6 倍伤害；两段之间 0.8 秒内再按 `J` 即可接招，超时回到第一段。
- 三种配置化敌人：异能者打手、异兽、精英异能者。
- 敌人会朝玩家直线追击，按间隔近身攻击，受击时闪红并显示血条。
- 玩家受击有无敌时间，生命归零后满血回到安全屋。
- 敌人和互动标记会随场景切换重建。

### 角色动画

- 跑步：`hero_run_down_0.png` 至 `hero_run_down_9.png`，10 帧循环。
- 普通攻击：`hero_attack_0.png` 至 `hero_attack_20.png`，21 帧，约 0.525 秒。
- 跑步和攻击都只维护一套左右方向素材，朝右时通过 `SpriteRenderer.flipX` 翻转。
- 攻击序列帧采用 120×120 透明画布；角色本体约 64 像素高，底边与脚底对齐，因此切回站立动画时不会跳位。

攻击帧由视频逐帧素材经过绿幕抠除、去绿边、缩放下采样和统一画布对齐后生成。后续替换素材时，只要保持 `hero_attack_<数字>.png` 连号命名即可，代码会从 0 开始加载，缺帧自动停止。

### 掉落与据点经营

- 击杀敌人掉落**异能残响**（青色晶体）和**突破素材**（琥珀晶体），走近自动拾取。
- 换场景时地上没捡完的掉落物会**自动结算进背包**，不会永久丢失。
- 安全屋五个交互点全部接实功能：

| 交互点 | 功能 |
|---|---|
| 炼化台 | 消耗 1 残响，三选一获得异能，并给 **+20 经验** |
| 情报板 | 接取委托「凝核之前」（清剿 2 名打手），追踪进度 |
| 休整床 | 回满生命 |
| 物资箱 | 查看残响 / 素材 / 炼化次数 / 累计经验 |
| 突破点 | 三项条件逐项展示，满足后可突破 |

炼化获得的三项异能会**真正影响战斗**：灼击（普攻 +4）、铁躯（受伤 −20%）、预判（冷却 −24%）。

### 境界与突破

- 境界：**觉醒者 → 凝核者**（`realms.json`）。
- 突破条件：累计经验 ≥ 100、炼化 ≥ 1 次、突破素材 ≥ 2。
- 突破后生命上限 +20、普攻伤害 +3、回满差额生命，**自动存档**并给完成提示。
- 累计经验用独立的 `totalExp` 字段，因为等级提升会把当前 `exp` 清零。

### 进度保存

- 单存档 JSON，记录数值、异能、境界、任务状态、资源数量、当前场景、玩家坐标、已击杀刷怪点。
- 存档时机：ESC 面板手动存档、**回到安全屋自动存档**、**突破后自动存档**。
- 已击杀的敌人重进场景不会复活。

### UI 与存档

- 常驻玩家血条。
- `Esc` 状态面板显示等级、生命、经验和已获得异能。
- 互动提示、事件选项、结果文字和战斗日志。
- 单存档 JSON，记录数值、异能、一次性互动、当前场景和玩家坐标。

存档位置由 Unity 的 `Application.persistentDataPath` 决定，文件名为 `save_01.json`。

## 数据驱动内容

主要配置表都位于 `Assets/Resources/Data/`：

| 文件 | 内容 |
|---|---|
| `scenes.json` | 场景注册表、场景图、碰撞遮罩和出生点 |
| `interactables.json` | 互动点、传送点和触发条件 |
| `events.json` | 文本事件、选项和效果 |
| `enemies.json` | 敌人属性、掉落数值和固定刷新点 |
| `abilities.json` | 异能及其数值加成（含炼化专属异能） |
| `quests.json` | 委托目标与奖励 |
| `realms.json` | 境界档位与突破加成 |

碰撞遮罩是纯文本：每行对应场景图的一行网格，`#` 表示不可走，`.` 表示可走。修改遮罩后重新进入 Play 即可生效。

## 命令行自检

先关闭 Unity 编辑器，避免项目被占用：

```powershell
& "E:\Unity\2021.3.19f1c1\Editor\Unity.exe" -batchmode -quit `
  -projectPath "E:\mygame" `
  -executeMethod ProjectSetup.RunAll `
  -logFile "E:\mygame\unity-run.log"
```

退出码 `0` 表示通过。自检会检查：

- 配置表和场景遮罩能否解析。
- 互动点、传送目标、事件效果引用的 id 是否存在。
- 三个场景能否加载，出生点是否可走。
- 敌人刷新点是否合法。
- 经验、异能、一次性互动和存档往返是否正常。
- 所有角色、场景、敌人和攻击序列帧是否使用 Point 过滤与 32 PPU。

渲染当前场景预览：

```powershell
& "E:\Unity\2021.3.19f1c1\Editor\Unity.exe" -batchmode -quit `
  -projectPath "E:\mygame" `
  -executeMethod ProjectSetup.CaptureWorldPreview `
  -logFile "E:\mygame\preview.log"
```

输出文件为项目根目录下的 `preview_world.png`。

### 数值闭环

从 JSON 配置实际推算，跑满一轮的产出：

| 来源 | 经验 | 残响 | 素材 |
|---|---|---|---|
| 打手 ×2 | 20 | 2 | 0 |
| 异兽 ×1 | 10 | 1 | 1 |
| 精英 ×1 | 30 | 2 | 1 |
| 委托奖励 | 20 | 0 | 0 |
| 炼化 1 次 | 20 | −1 | 0 |
| **合计** | **100** | **4 余** | **2** |

突破门槛是经验 100 / 炼化 1 / 素材 2，**刚好卡在线上，没有余量**。这是刻意的设计：要求玩家把内容跑完。但也意味着**漏掉任何一只怪或任何一个掉落物都会差一口气**。

已为此加了两道保险：掉落物换场景自动回收、委托进度按历史击杀数回填。

## 像素资源约定

- 基准分辨率：640×360。
- Pixels Per Unit：32。
- 贴图过滤：Point。
- 压缩：无压缩。
- 关闭 Mip Maps。
- **角色整体缩放：1.5 倍**（`PixelArtSettings.CharacterScale`）。

`Assets/Resources/Art/` 下的新贴图会自动应用像素导入设置，不需要逐张手动修改 Inspector。

### 关于 CharacterScale

精灵本体按 48×64 出图（PPU 32 → 世界 1.5×2 单位）。乘以 1.5 之后：

- 主角在房间里高约 96px，正好是门高（148px）的 65%，符合真实人体比例。
- 主角、敌人、掉落物、互动标记**共用同一个倍数**，否则主角会明显比怪高出一头。

改这一个常量就能整体调大调小。取 1.5 是因为 640×360 画面在 1280×720 窗口下放大 2 倍，1.5×2 = 3，每个源像素仍然是整数倍，不会出现像素抖动。

**没有跟着缩放的东西**：普攻判定范围（`Reach` / `Radius`）、敌人仇恨与攻击距离。这些都还是世界单位原值，如果想连带调整，改 `PlayerCombat` 和 `enemies.json` 即可。
