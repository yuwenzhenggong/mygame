# 下一阶段美术资源准备清单（建议稿）

日期：2026-11-25。基于当前仓库代码与原始图片检查，尚未在 Unity 中实测画面。

本文是用于讨论和备料的建议清单，不代表已确认新增玩法或已安排制作。暂以“小规模开发、完成一段约 15～20 分钟的第一章试玩”为目标；优先复用三张现有地图和主角，补齐敌人、战斗信息及异常调查表现。

## 3. 先统一的美术规范

- 风格建议：沿用现有黑发现代服装主角与像素场景，做“现代都市 + 异常现象”。安全屋保留暖色，异常区域用冷色点缀；具体配色仍待确认。
- 先做一张风格对照板：主角、打手、异兽、精英、安全屋局部、街道局部、技能图标和 UI 色板放在一起。风格通过后再扩展动画。
- 游戏基准分辨率为 640×360，世界精灵为 32 PPU，角色根节点另有 1.5 倍缩放。资源应在实际显示大小下检查。
- 世界角色和特效交付透明背景 PNG；帧之间保持画布、脚底、身体比例和武器方向一致，不随动作自动裁边。
- 当前三个背景直接作为整图加载。画图时不要随意移动道路、门和障碍物；改动布局时需同步碰撞遮罩、出生点、传送点及交互坐标。
- 当前贴图导入上限为 2048，不直接交付 4K 成品作为现有背景的替换图。

## 4. P0：下一批优先制作

| 资源包 | 建议数量 | 交付内容与规格 | 用途及顺序 |
| --- | --- | --- | --- |
| 风格基准 | 1 张对照板 | 主角沿用现有造型；明确敌人剪影、像素颗粒、光源和 UI 配色 | 所有批量出图之前完成 |
| 三类敌人形象 | 3 个角色 | 打手：现代街头服装和清晰出拳姿态；异兽：低伏、可读的扑击轮廓；精英：与打手有明确体型/装备区别。先出透明站姿，各用统一画布，身体比例参照现有主角 | 第一优先级，直接消除色块占位感 |
| 打手基础动作 | 先完整做 1 个敌人 | 建议待机 4、移动 6、攻击 6、受击 2、死亡 4 帧，共约 22 帧。攻击必须包含可识别蓄力、出手和收招；帧数为估算，动作长度由战斗实现确定 | 先接入并验证一个敌人，再扩展其他敌人 |
| 安全屋功能物件 | 补 4 项，保留床 | 情报板、炼化台、物资箱、突破地面标识；建议透明独立物件。大小由房间布局决定，按主角 64 像素本体作参照 | 让功能位置与看到的物件一致；现有床直接复用 |
| 地图出入口 | 2 类标识 | 安全屋门口/出口高亮、林区入口/返回点提示；可复用轮廓和箭头 | 减少迷路；优先局部叠加，不重画全地图 |
| 技能图标 | 7 枚 | 灵视、念力、回响、再生、灼击、铁躯、预判。建议原生 24×24；先用轮廓区分，再用颜色辅助 | 常驻技能栏和背包复用；不要在图里烘焙快捷键或冷却数字 |
| 小型 UI 图标 | 4 枚 | 任务、调查、交互、关闭，建议 16×16 或 24×24；残响和素材直接复用现有图 | 提高信息识别，避免每个面板另做一套 |
| UI 组件规范 | 1 套小组件 | 32×32 技能槽建议稿、选中/禁用边框、血条与任务底板；沿用暖白和深色描边 | 面板由代码拼装，冷却遮罩和文字由 UI 动态绘制 |
| 攻击预警 | 3 类图形 | 圆形、扇形、直线/冲刺带；可用 64×64 透明基础图或程序绘制 | 与近战、范围攻击和扑击对应；不为每种颜色重复出图 |
| 最小战斗特效 | 3 类效果 | 命中火花、念力冲击、灵视扫描；建议 4～6 帧或程序效果，先保证不遮住敌人和地面预警 | 配合打击反馈，不先做七套大型技能特效 |
| 异常调查素材（方向确认后） | 1 套可复用线索 | 左右脚印各 1、异常影子 1、线索闪光 4 帧；脚印建议 16×16/16×24，其他按场景显示大小确定 | 支撑一段完整灵视调查，不先批量制作整个章节线索 |

角色画布建议：人形敌人可先试 64×80 的站立/移动画布、96×96 的攻击画布；异兽可试 80×64。这里是新制作建议，不能把旧图片直接拉伸成该大小。应先确认脚底和身体在画布中的位置，再冻结规格。

## 6. 接入与交付注意事项

1. 当前导入器强制 `SpriteImportMode.Single`，角色帧通过连续文件名加载。优先交付逐帧 PNG；若交付图集，需另安排切图及导入代码，不能直接放进去就使用。
2. 建议保留可编辑源文件，同时提供逐帧 PNG、动画预览 GIF/视频和帧时序表。参考图、源文件和预览不放入游戏运行时 `Resources`。
3. 每个动作注明：循环与否、每帧时长、攻击蓄力结束点、命中帧、脚底位置；冲刺类注明位移由代码驱动。
4. 地面预警、线索和功能物件可以独立交付，但当前代码尚没有完整接入这些新资源。美术清单与功能开发需配套安排。
5. UI 文字保留为动态文本；图标禁用态、冷却数字、进度变化优先由程序绘制，不输出大量重复图片。
6. 保存素材来源与使用许可信息。若使用 AI 生成图，先保证同角色各帧造型一致，再人工检查透明边缘、抖动、脚底与方向。

## 7. 推荐制作顺序

风格对照板 → 三类敌人站姿 → 打手完整动作与攻击预警 → 七枚技能图标和技能栏 → 安全屋功能物件 → 一段异常调查素材 → 异兽/精英动作 → 首章 Boss。

首轮验收看实际游戏尺寸：能认出敌人、能判断攻击危险、能找到安全屋功能、能识别技能。地图精修和角色批量动画在这一轮验证后扩展。
